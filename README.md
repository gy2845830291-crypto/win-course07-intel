## 这是什么

本课靶场由课程教研组**从零编写**，用途只有一个：让学员在一个已知、可控的 Windows
原生样本上，完整走一遍"定位校验函数 → 还原卡密算法 → 给出 patch 点"的逆向流程。

它不是任何第三方商业软件的副本、改名版或重打包版。教研组在此明确授权学员对
本靶场样本做静态分析、动态调试、反汇编、patch 与重打包，并可公开讨论分析过程。

## 授权声明

1. 任何学员可在本地环境对本靶场样本做静态分析、动态调试、反汇编、patch 与重打包；
2. 可公开讨论分析过程、算法还原结果与 patch 方案；
3. 课堂答案随课发布。

## 已知样本特征（教研组提供的预习资料，便于学员少走弯路）

教研组在发布前对样本做了基础测绘，以下为实测结果，供学员对照：

- 架构：x64，`Machine=0x8664`，`Magic=0x020B`（PE32+）
- 导入表仅三个系统 DLL：`KERNEL32.dll` / `USER32.dll` / `ADVAPI32.dll`
  （未导入 `mscoree.dll`，即外层不是直接运行的托管程序）
- 文件尾部含 ClickOnce 部署清单片段（`asm.v3`、`requireAdministrator`）
- 节区熵值采样：`.rsrc` ≈ 7.986、`.text` ≈ 7.539、`.ace0` ≈ 6.934
  （高熵提示载荷为压缩或加密状态）
- 静态字符串扫描中，卡密 / 注册码 / 激活码 / license / serial 类关键词零命中

**教研组提示**：上述特征意味着校验逻辑大概率不在外层引导器中。
本课的教学目标之一，正是训练学员识别"外层是壳 / 引导器"这一情况，
并掌握先解包、再定位的正确顺序——直接对引导器下刀是新手最常见的误区。

## 实验任务

1. 确认外层结构：它是不是真正的程序本体？如果不是，载荷在哪一层？
2. 取得解包后的真实程序模块（ClickOnce 缓存、内存 dump、或解包工具任选）。
3. 定位校验入口，还原卡密编码与校验算法。
4. 给出 patch 点：文件、偏移、替换字节，以及验证方法。

## 使用约定

- 样本与修改产物仅限本地与课堂环境使用。
- 不要把 patch 后的样本以任何形式分发到公开渠道。
- 讨论 patch 方案时贴 diff 与方法名，不要贴完整可安装二进制。
